# Análise de Configurações Padrão - GCP

Esta seção do repositório é dedicada à análise das configurações padrão dos seguintes serviços do Google Cloud Platform (GCP):

- **Google Compute Engine:** Máquinas Virtuais
- **Google Cloud Storage:** Armazenamento de Objetos
- **Google Cloud SQL:** Bancos de Dados Relacionais Gerenciados
- **Google Cloud IAM (Identity and Access Management):** Gestão de Identidade e Acesso
- **Google GKE (Google Kubernetes Engine):** Kubernetes Gerenciado
