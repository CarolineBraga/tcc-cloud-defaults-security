# Análise de Configurações Padrão - AWS

Esta seção do repositório é dedicada à análise das configurações padrão dos seguintes serviços da Amazon Web Services (AWS):

- **Amazon EC2 (Elastic Compute Cloud):** Máquinas Virtuais
- **Amazon S3 (Simple Storage Service):** Armazenamento de Objetos
- **Amazon RDS (Relational Database Service):** Bancos de Dados Relacionais Gerenciados
- **AWS IAM (Identity and Access Management):** Gestão de Identidade e Acesso
- **Amazon EKS (Elastic Kubernetes Service):** Kubernetes Gerenciado
