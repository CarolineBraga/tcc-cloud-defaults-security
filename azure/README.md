# Análise de Configurações Padrão - Azure

Esta seção do repositório é dedicada à análise das configurações padrão dos seguintes serviços da Microsoft Azure:

- **Azure Virtual Machines:** Máquinas Virtuais
- **Azure Blob Storage:** Armazenamento de Objetos
- **Azure SQL Database:** Bancos de Dados Relacionais Gerenciados
- **Azure AD (Active Directory):** Gestão de Identidade e Acesso
- **Azure AKS (Azure Kubernetes Service):** Kubernetes Gerenciado
